# Text Monkey — Brand Kit

Tagline: "Just text. We'll handle the monkey business."
Product: AI texting volunteer scheduling system. Tone: chill, funny, friendly.

## Colors
- Banana Yellow #FFD23F — primary brand background
- Cocoa #3B2314 — wordmark, headings, body text on yellow/cream
- Monkey Brown #6B3E26 — secondary, dark surfaces
- Face Tan #F2C49B — soft accent
- Screen Lime #9BE564 — highlights, success, CTA accents
- Shade Black #141414 — dark UI
- Cream #FFF8E6 — light page background

## Type
- Logo / headlines: Bagel Fat One (Google Fonts), uppercase, often rotated -3°
- Body / UI: DM Sans (Google Fonts), 400/600

## Files
- textmonkey-logo-stacked-*.png — monkey above wordmark (yellow, dark, transparent)
- textmonkey-logo-horizontal-*.png — monkey left of wordmark, for site headers
- textmonkey-mark-transparent.png — monkey only
- textmonkey-wordmark-*-transparent.png — wordmark only (brown, yellow, white)
- textmonkey-app-icon-1024-square.png — App Store / Play upload (platform rounds corners)
- textmonkey-app-icon-1024-rounded.png — for mockups
- textmonkey-favicon-512/192.png — web favicon / PWA
- textmonkey-brand-colors-type.png — visual reference sheet

## Usage
- Default: Cocoa wordmark on Banana Yellow or Cream. On dark (Cocoa/Monkey Brown), use the Yellow wordmark.
- Keep the monkey's sunglasses and lime phone screen intact; don't recolor the mark.
