# Tonight's one-time cloud test exception

The authorized operator can record one grant through `POST /api/cloud-texting/demo/quiet-test`, with `signup_phone`, `admin_phone` and `confirmed: true`. Supply only the exact privately authorized tester pair after checking their current Google sender and configured sessions. The existing verified superadmin login is required. The server records the actor, timestamp, sender, complete session specifications and limited purposes in a durable audit. Recording the grant performs no model call, intake or send, creates no recipient session and grants no consent or review authority.

The exception expires at **2026-10-06 05:00 UTC**, which is **October 5 at 11 PM America/Denver**. It cannot renew itself or accept a different expiry. Saved 21:00–07:00 quiet hours remain unchanged. Expiry is checked from the delivery clock on every use and caps the connector's native submission deadline; it does not depend on a cleanup job, running timer or laptop.

The signup tester scope covers signup replies plus reminders and confirmations for the existing privately authorized acceptance assignment. The admin tester scope covers coordinator notifications, escalation notifications and admin replies. Other recipients, manual messages and outreach do not receive this exception. Existing STOP, consent, registration/session, Gloo composition, exact review, freshness, eligibility and uncertain-submission holds still apply. Revoking the recorded audit or changing the sender/session invalidates the exception. Source tests use fictional data; runtime enrollment and actual delivery remain separate verified actions.
