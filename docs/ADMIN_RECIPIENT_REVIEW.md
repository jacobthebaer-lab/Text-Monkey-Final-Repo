# Review an existing primary admin recipient

In the connected Settings page, open **Replace the primary with an existing roster contact**. Review the exact mobile number, contact name and current primary. A separate, unchecked confirmation records the church administrator's attestation that the number belongs to the reviewed person and that the person agreed to church admin text updates. It does not pretend the other person checked the first-person consent box.

The review expires after ten minutes and binds the contact identity, profile, qualifications and current primary/workspace revision. Changed reviews, foreign-owned records, inactive contacts, opt-outs and reused approvals are rejected. Confirmation preserves the contact's ID, name, preferences and qualifications, updates the workspace's primary name/number, and pauses the previous primary through the existing replacement behavior. Other volunteer records are untouched. Saving does not send a message or create volunteer signup authority.

For the existing bounded Google admin connection check, the recipient must already have an explicitly configured private recipient session. Enrollment records the exact sender and session; missing, changed, expired or revoked evidence holds admin texts. This proof covers only coordinator notifications, escalation notifications and admin replies. It grants no volunteer signup, reminder, manual-send or general automation authority. A new session requires a fresh, truthful consent enrollment through the same exact-contact review. The current owner can re-review its own primary; another owner cannot claim it. Do not represent another person's mobile as your own to renew it.

A connection check is a separate explicit action. Existing provider policy, pause controls, exact recipient scope, Gloo composition, exact human review, quiet hours, STOP and uncertain-delivery holds remain in force. Enrollment neither configures nor enables a transport or scheduler. Source tests use synthetic contacts and services; no real enrollment or delivery is established by them.
